### Quickstart
```bash
# Install dependencies
pip install -r requirements.txt

# Launch interactive presentation dashboard
cd ML-CP
streamlit run dashboard.py

# Or run the upgraded ML training and evaluation pipeline
python run_pipeline.py
```
